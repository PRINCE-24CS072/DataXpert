Project Overview

Project Title

AI-Assisted Business Data Analytics & Management System

Application Name: DataXpert

Description

DataXpert is a comprehensive web application designed to help businesses analyze their data through AI-powered insights. The platform combines advanced analytics, machine learning, and an intuitive user interface to provide actionable business intelligence. Built with modern web technologies and featuring a stunning glassmorphism design inspired by leading AI tools, DataXpert offers enterprise-grade features with consumer-grade simplicity.

Key Features

Advanced Authentication

Dual authentication with email/password and Google OAuth 2.0 integration. Intelligent flow handling for signup/login scenarios with profile picture synchronization.

Interactive Dashboard

Real-time visualizations powered by Chart.js with glassmorphism design. Track sales, expenses, profits with gradient stat cards and animated charts.

AI-Powered Analysis

ChatGPT-style interface for natural language queries. Advanced NLP processing with intent recognition, entity extraction, and predictive analytics.

Team Collaboration

Multi-user team management with role-based permissions. Share insights and collaborate on data analysis across your organization.

Smart Anomaly Detection

Z-score based anomaly detection with automatic alerts. Proactively identify unusual patterns in your business data.

Natural Language Processing

Advanced NLP engine that understands business queries in plain English. Extract insights through conversation, not complex queries.

Responsive Design

Fully responsive interface that works seamlessly across desktop, tablet, and mobile devices with modern glassmorphism UI.

Enterprise Security

JWT-based authentication with 7-day expiry, encrypted data storage in Supabase PostgreSQL, and CORS protection.

Technology Stack

Frontend

HTML5 CSS3 (Modern) JavaScript (ES6+) Chart.js 3.x Inter Font Font Awesome 6.4

Features glassmorphism design with backdrop-filter blur effects, gradient backgrounds, CSS custom properties for theming, and cubic-bezier animations.

Backend

Python 3.8+ Flask 2.x Flask-CORS PyJWT python-dotenv Werkzeug

RESTful API architecture with token-based authentication decorator, standardized JSON responses, and comprehensive error handling.

Database

Supabase PostgreSQL 14+ supabase-py

Cloud-based PostgreSQL with real-time capabilities, automatic backups, and row-level security policies.

Data Analysis & AI

Pandas NumPy SciPy Custom NLP Engine Statistical Analysis

Intent recognition, entity extraction, time series analysis, forecasting, and Z-score anomaly detection.

Authentication & Security

Google OAuth 2.0 JWT (HS256) SHA-256 Hashing google-auth

Multi-scenario Google OAuth flows with intelligent signup/login handling, 7-day JWT expiry, and secure password hashing with salt.

Design System

Glassmorphism Gradient Backgrounds CSS Variables Responsive Grid Smooth Animations

Modern AI tool aesthetic inspired by ChatGPT and Notion, featuring frosted glass effects, purple-to-pink gradients, and fluid transitions.

Quick Start

1. Clone the Repository

git clone https://github.com/yourusername/dataxpert.git
cd dataxpert

2. Setup Backend

cd backend
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your credentials
python app.py

3. Setup Frontend

cd frontend
# Update js/config.js with your Google Client ID
# Open index.html in a browser or use a local server
python -m http.server 5500

See the detailed setup guide for complete instructions including Supabase configuration and Google OAuth setup.
